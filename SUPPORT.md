# Getting help

## Read the docs first

Most questions are answered here:

| Question | Where to look |
| --- | --- |
| How do I install and run it? | [README: Quick start](README.md#quick-start) |
| Something fails with an error message | [Troubleshooting and FAQ](docs/troubleshooting.md) |
| How does an endpoint behave? | [HTTP API reference](docs/api.md) |
| How do the parts fit together? | [Architecture](docs/architecture.md) |
| How do I run tests or change code? | [Development guide](docs/development.md) |
| What were the vulnerabilities and how were they fixed? | [Remediation record](docs/vulnerabilities.md) |

## Ask a question

If the docs don't help, [search the issues](https://github.com/Kandel-Bibas/TicketSenpai/issues?q=is%3Aissue)
(including closed ones), then
[open a question](https://github.com/Kandel-Bibas/TicketSenpai/issues/new?template=question.yml).
Include:

- What you are trying to do.
- What you ran and the full output or error.
- Your OS, `node --version`, and `python3 --version`.

## Report a bug or request a feature

Use the [issue templates](https://github.com/Kandel-Bibas/TicketSenpai/issues/new/choose).
See [CONTRIBUTING.md](CONTRIBUTING.md#reporting-bugs) for what makes a good report.

## Security issues

Never post security problems publicly. Follow [SECURITY.md](SECURITY.md).

## What we can't help with

TicketSenpai is a local learning project. We cannot help with deploying it to a
server, using it to sell real tickets, or processing real payments.
